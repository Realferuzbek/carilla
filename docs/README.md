# Docs

This repo ships static UI prototype and an optional backend scaffold.

- `frontend/index.html` is the production-facing static UI prototype. It can be opened directly or served by any static host.
- `backend/` is optional and only needed if you want the upload/log endpoints during local development.
- `e0_strong_colab_drive_api.md` explains reliable E0_strong generation in Colab with Drive API upload.
